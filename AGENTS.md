# AGENTS.md

Patriota: a Brazilian-flag-inspired VS Code color theme (dark and light), packaged as a VS Code extension and
validated by Python scripts. The theme JSON is the product; the light variant is generated from the dark one.

## Stack

- VS Code theme JSON in `themes/`; extension entry `src/extension.js` (`engines.vscode` `^1.72.0`); `media/` holds the extension assets
- Python 3.8+ for validation, generation and preview (`pyproject.toml`); tests with `pytest` (dev extra)
- Node for packaging and publishing (`vsce`, `ovsx`) and screenshots (`code-server`); `.nvmrc` pins the version
- Releases: `semantic-release` (`.releaserc`) on push to `master`, driven by Conventional Commit titles

## Commands

```sh
npm ci                                 # Node dependencies (package-lock.json)
npm run validate                       # python3 scripts/validate_theme.py: colors and contrast
npm test                               # python -m pytest tests (39 tests)
python3 scripts/build_light.py         # regenerates themes/patriota-light-color-theme.json
python generate_preview.py             # visual preview of the theme
npm run package                        # vsce package
npm run screenshots                    # needs code-server on PATH (or CODE_SERVER_BIN)
```

## Structure

- `themes/patriota-color-theme.json`: the dark theme, edited by hand
- `themes/patriota-light-color-theme.json`: the light theme, generated by `scripts/build_light.py`
- `src/extension.js`: extension entry point; `media/`: icon, `pet.js`/`pet.css`, `flag.js`
- `scripts/`: `validate_theme.py` (colors and contrast), `build_light.py`, `take_screenshots.js`, `make_icon.js`, `publish.sh`
- `tests/`: pytest suites for the manifest, selection contrast and the validators
- `generate_preview.py`: builds the preview from the theme; `images/` and `docs/readme/` hold the screenshots
- `index.html`: the GitHub Pages site (`pages.yml`); `CHANGELOG.md` is maintained by the release pipeline

## Gotchas

- Do not hand-edit `themes/patriota-light-color-theme.json`. Change the dark theme and run `python3 scripts/build_light.py`.
- Do not version by hand. Releases come from Conventional Commit titles through `semantic-release`.
- Three files are over the 150-line rule today: `README.md` (192), `generate_preview.py` (267) and `scripts/validate_theme.py` (169).
- `npm test` needs `pytest` installed for the Python in use; CI installs it in `validate.yml`.
- The pet view (`patriota.petView`) loads `media/pet.js`, `media/pet.css` and `media/flag.js` from `src/extension.js`; renaming them breaks it.
